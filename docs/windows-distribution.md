# Windows distribution proposal

The application currently builds `bin/kompeg.exe`; no installer has been built or verified. This proposal keeps the application and installation responsibilities separate.

## Download eligibility

One-click FFmpeg setup is for incomplete environments. If both actual FFmpeg and ffprobe version checks succeed, the UI disables download and explains how to choose another local version. The native API repeats the live checks before starting either built-in or custom downloads, so stale frontend state cannot bypass the guard. Finding only one working tool does not block completion.

Explicit `KOMPEG_FFMPEG`, `KOMPEG_FFPROBE`, `FFMPEG_PATH` or `FFPROBE_PATH` values take precedence over application settings. Downloads and manual configuration writes are blocked until those overrides are corrected/removed and the application is restarted; an invalid override is not silently bypassed. An ordinary working PATH installation blocks redundant downloads while still allowing deliberate local-path selection. Active jobs and duplicate downloads keep their existing native guards.

## Two release artifacts

- **No-install application:** distribute kompeg.exe with the project license, dependency notices and usage instructions (normally together in a small ZIP). The frontend is embedded in the executable. Settings and downloaded FFmpeg remain in the user's AppData directories; this is not an entirely self-contained portable directory. FFmpeg is external and WebView2 Runtime is required.
- **Installer:** a separate `kompeg-<version>-windows-x64-setup.exe` generated by an established installer builder. The payload includes the same kompeg.exe and notices. The installer extracts them to `%LOCALAPPDATA%/Programs/kompeg`, creates Start Menu/optional desktop shortcuts, registers an uninstaller and handles upgrades with a stable application identity. It preserves user settings/media and does not change system PATH.

Inno Setup is the proposed builder, not yet an adopted dependency. Its non-administrative installation mode supports per-user installation/uninstall registration. The installer is a compressed executable containing its installation engine and the application payload: it extracts the application, rather than making the running application overwrite or extract itself. Running kompeg.exe never starts an installation wizard. See [Inno Setup non-administrative mode](https://jrsoftware.org/ishelp/topic_admininstallmode.htm).

WebView2 should be detected before launching the application. If missing, an online installer can offer Microsoft's Evergreen Bootstrapper; an offline edition would include Microsoft's standalone installer after its redistribution terms and package verification are settled. Existing runtimes are reused. FFmpeg setup remains an explicit first-run/in-app operation rather than an implicit installer download. See [Microsoft WebView2 distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).

Installer compilation, clean-machine install/upgrade/uninstall, missing-WebView2 behavior and an offline distribution remain future work. No installer or Windows installation was run for this change.
