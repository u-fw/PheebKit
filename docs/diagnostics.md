# Local diagnostics — 0.2.0-beta.7

Settings → 故障诊断 generates a local JSON preview. Saving opens a native JSON save dialog and writes the exact preview bytes. Nothing is uploaded. Options changed after generation invalidate the preview; a snapshot expires after ten minutes. At most four previews, each at most 512 KiB, are retained in memory.

The report uses a positive field/value allowlist rather than attempting to redact an arbitrary log. It includes application/Go/Wails versions, validated Git revision and modified-build flag, numeric Windows version/build, architecture/logical CPU count, FFmpeg/ffprobe availability/source category/numeric release, cached encoder availability/GPU vendor categories, queue state counts and boolean/status flags for local storage. It never initiates GPU qualification or FFmpeg processes. A busy capabilities scan is reported as such, avoiding waiting for that scan.

Recent job summaries are off by default. Opting in permits 1–50 latest records with operation/codec/state enums, classified failure category and output-verification/warning counts. Unknown values become generic categories. No error text, command, log or media metadata is copied. The summary is intentionally less detailed than local history and may require follow-up investigation.

Paths, filenames, usernames, machine names, environment values, raw logs/errors, command arguments, download URLs, custom parameters, project documents and media contents are excluded. The report still reveals general system/software configuration and coarse processing activity; review the full preview before voluntarily attaching it to an issue. Local project/history files themselves contain paths and must not be attached without separate review.

Export refuses known input/result/configuration files and their aliases. Saving uses a flushed temporary file and replacement; a cancelled dialog writes nothing. There is no upload endpoint, automatic attachment, background telemetry or raw-log bypass. File writing and snapshot equality have automated coverage; the native dialog remains a separate manual acceptance item.

Regressions seed sensitive sentinel strings across untrusted environment/capability/job fields, confirm none appear in the allowlisted JSON, verify optional-summary limits, immutable preview bytes, expiration/cache bounds, alias protection and nonblocking capability reporting. A disposable browser fixture verified default exclusion, preview-required save, exact snapshot token, option invalidation, rejection of count 0, custom count 3 and expired-preview feedback. The 375px dark layout had no horizontal overflow or console errors; the expected Wails browser-only warning was present. Fixture, server, viewport override and tab were removed. These checks do not prove native IPC/dialog behavior. The full frontend suite has 101 tests in 20 files.
